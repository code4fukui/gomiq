# gomiq

ごみの分別知識を試す、テンポの速いクイズゲームです。福井県鯖江市の燃えるごみ・燃えないごみの分類に基づき、各ラウンドで正しいアイテムを見分けて「燃やす」ことが目標です。

## デモ

ブラウザでプレイする: **https://github.com/code4fukui/gomiq

## 遊び方

1. 画面に5つのごみアイテムが表示されます。
2. 上部に「3コ燃やせ！」のような課題が表示されます。
3. 燃えるごみだと思うアイテムをクリックします。
    - **正解**のアイテムを選ぶと赤くなります。
    - **不正解**（燃えないごみ）のアイテムをクリックすると、正しい分類が表示され、ラウンドがリセットされます。
4. 指定された数の燃えるごみをすべて正しく選ぶとラウンドクリアです。スコアは下部に表示されます。

## 特徴

- 実際のごみ分別ルールに基づいた、シンプルなクイズ形式のゲーム。
- ごみアイテムのデータを動的に読み込むため、毎回異なる問題を楽しめます。
- 正解数と総プレイ回数を記録し、リアルタイムで正解率を表示します。
- いつでもスコアをやり直せるリセットボタンを搭載。

## データと出典

このゲームは、福井県鯖江市の実際のごみ分類データを使用しています。

- **アプリケーション:** 福野泰介氏のオリジナル作品「ごみ燃やしゲーム」をベースにしています（[福野泰介の一日一創](http://fukuno.jig.jp/1514)）。(APP: CC BY)
- **データ:** [odp SPARQL Endpoint](http://sparql.odp.jig.jp/) から動的に取得しています。(DATA: CC BY)
